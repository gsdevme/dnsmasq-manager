# The `serve` Command Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `dnsmasq-manager serve` runs a REST API, an external-dns v0.24.0 webhook provider and a read-only web page over one managed dnsmasq hosts file.

**Architecture:** Small packages under `internal/`. `records` owns the types, the validation policy and a mutex-guarded store; `hostsfile` renders, parses and atomically saves the one managed file; `api`, `webhook` and `web` are `net/http` handlers over the store; `server` binds and runs the listeners; `cli` wires them from environment config.

**Tech Stack:** Go 1.27 standard library (`net/http`, `log/slog`, `html/template`, `encoding/json`, `net/netip`), cobra (already present). Docker for the integration and end-to-end harnesses.

**Spec:** [`docs/superpowers/specs/2026-11-19-serve-design.md`](../specs/2026-11-19-serve-design.md). Every implementer reads the spec sections named in their task; the spec's wording wins over this plan where they differ.

## Global Constraints

- Module path `github.com/gsdevme/dnsmasq-manager`; Go version from `go.mod`. **No new third-party dependency.**
- Minimums are Alpine 3.23 and dnsmasq 2.91; no code or probe for older ones.
- No private zone, LAN address or token in the repo. Tests and docs use `home.example.test`, record addresses in `10.0.0.0/24`, IPv6 examples in `fd00:10::/64`.
- Test-driven: write the failing test, run it and see it fail, then the code. Table-driven tests in an external `_test` package, as in `internal/cli/cli_test.go`.
- Comments: a doc comment on every package, exported type and function, saying what it is for and what callers need to know. No inline narration, no change history, no commented-out code.
- `make test` (runs with `-race`) and `make lint` pass at the end of every task. Never touch the live DNS host.
- Commits: Conventional Commits, one per task, subject ≤ 72 characters, never `chore`. The orchestrator commits; workers leave changes uncommitted unless told otherwise.
- Webhook media type, exact: `application/external.dns.webhook+json;version=1`.
- Managed file name, exact: `dnsmasq-manager.hosts`. Temporary files: `.dnsmasq-manager.hosts.*`.

## Review Focus

Inputs the spec implies but does not spell out. Each has a test in the task named.

1. **Both APIs writing at once.** Expect serialised writes and no lost update. Task 4: `TestStoreConcurrentUpdates` (50 goroutines, each adding a distinct name, run under `-race`; all 50 present, saver called with strictly growing states).
2. **The hosts directory becomes unwritable or disappears while running.** Expect a 500, the in-memory state unchanged, and the next write to work once it is back. Task 3: `TestSaveFailsWhenDirMissing`; Task 4: `TestStoreKeepsStateWhenSaveFails`; Task 8: `TestPutReturns500WhenSaveFails`.
3. **Change sets external-dns can legally send but a naive handler mishandles:** omitted lists, `null` lists, `updateOld` without a matching `updateNew`, the same name in `delete` and `create`, a delete of something absent. Expect no panic and the documented order. Task 9: `TestApplyChangeSetShapes`.
4. **Address spellings:** IPv4-mapped IPv6 (`::ffff:10.0.0.80`), a zone suffix (`fe80::1%eth0`), non-canonical IPv6 (`fd00:10:0:0::80`), leading zeros (`010.0.0.80`), an IPv4 address given for `AAAA`. Expect refusal, or canonical form for the non-canonical one. Task 1: `TestParseValues`.
5. **Oversized and never-ending requests.** Expect 413 on REST over 64 KiB, 500 on webhook over 1 MiB, and server timeouts that close a stalled connection. Tasks 8, 9 and 11: `TestPutBodyTooLarge`, `TestWebhookBodyTooLarge`, `TestServerClosesStalledConnection`.

```go
// name sharing one Source; TXTs sorted by Name, one per Name.

func (s State) Equal(o State) bool
func (s State) Source(name string) (Source, bool)

func (d *Draft) DeleteName(name string)
func (d *Draft) SetTXT(t TXT)
func (d *Draft) DeleteTXT(name string)
func (d *Draft) DeleteTXTOwnedBy(recordName string)
func (d *Draft) State() State                 // canonical; sorts and dedupes Values

type Change struct { Name string; Type Type; Before, After []netip.Addr } // nil = absent
func Diff(before, after State) []Change       // A/AAAA only, sorted

var ErrConflict = errors.New("conflict") // wrapped by ownership refusals (used by Tasks 8, 9)

const MaxValues = 16
func (p Policy) NormalizeName(name string) (string, error)
func (p Policy) ParseValues(t Type, values []string) ([]netip.Addr, error) // sorted, unique
func (p Policy) CheckRecord(r Record) error // name already normal, values in family and prefixes, 1..MaxValues, known Source
func (p Policy) CheckTXT(t TXT) error
func (p Policy) Check(s State) error        // every record and TXT, and that s is canonical
```

### Task 8: `api` (REST)

Spec: "REST API", "Health". Depends on Tasks 4, 6, 7.

**Files:** Create `internal/api/api.go`, `api_test.go`.

**Produces:**

```go
package api

type HealthChecker interface { Check(ctx context.Context) health.Result }
// NewHandler returns the REST listener's handler, already wrapped in the
// history middleware (listener "api", every request except /healthz).
func NewHandler(store *records.Store, checker HealthChecker, token string, hist *history.Log, logger *slog.Logger) http.Handler
```

Routes, bodies and status codes are the spec's, exactly. Details the spec leaves:
- Token comparison: SHA-256 both sides, then `subtle.ConstantTimeCompare`. The scheme word `Bearer` is matched case-insensitively.
- `PUT` on a new name or an `api` name sets source `api`. On an `external-dns` name without `force=true`: 409, error wrapping `records.ErrConflict`. With it: `Set(..., SourceAPI)` and `DeleteTXTOwnedBy(name)`.
- `DELETE` on an `external-dns` name follows the same 409 / force rule; with force, also `DeleteTXTOwnedBy(name)`. On an absent name: 204 without force.
- `force` and `type` accept only `true`/`false` and `A`/`AAAA`; anything else is 400. A `DELETE ?type=CNAME` is 422.
- The `{name}` path value is normalised with `Policy.NormalizeName`; failure is 422.
- History summaries: `set <name> <type>`, `delete <name>` or `delete <name> <type>`, `list`; on failure the error message.
- After a successful write call `records.LogChanges(logger, "api", history.RemoteIP(r), before, after)`.
- JSON decoding uses `DisallowUnknownFields` and refuses trailing data.

```go
	DNSName          string            `json:"dnsName,omitempty"`
	Targets          []string          `json:"targets,omitempty"`
	RecordType       string            `json:"recordType,omitempty"`
	SetIdentifier    string            `json:"setIdentifier,omitempty"`
	RecordTTL        int64             `json:"recordTTL,omitempty"`
	Labels           map[string]string `json:"labels,omitempty"`
	ProviderSpecific []Property        `json:"providerSpecific,omitempty"`
}
type Property struct { Name string `json:"name,omitempty"`; Value string `json:"value,omitempty"` }
type Changes struct {
	Create    []Endpoint `json:"create,omitempty"`
	UpdateOld []Endpoint `json:"updateOld,omitempty"`
	UpdateNew []Endpoint `json:"updateNew,omitempty"`
	Delete    []Endpoint `json:"delete,omitempty"`
}

// Adjust returns the endpoints the service would accept, in the form
// GET /records returns them, and a description of each one dropped.
func Adjust(policy records.Policy, in []Endpoint) (kept []Endpoint, dropped []string)
// Apply applies c to d in the order delete, updateOld, updateNew, create.
// Any refusal returns an error naming the entry; d must then be discarded.
func Apply(policy records.Policy, d *records.Draft, c Changes) error
// Endpoints returns the state as GET /records serves it.
func Endpoints(s records.State) []Endpoint

// NewHandler returns the webhook listener's handler: history outermost
// (listener "webhook": every POST /records, anything with status >= 400),
// wrapping the allowlist, so refused (403) requests are recorded, then the
// routes.
func NewHandler(store *records.Store, allowed []netip.Prefix, hist *history.Log, logger *slog.Logger) http.Handler
```

Details the spec leaves:
- Routes: `GET /{$}`, `GET /records`, `POST /records`, `POST /adjustendpoints`. All replies, including 403, 404 and 405, carry `Content-Type: MediaType`.
- Negotiation body: `{"include":[...zones]}`. `GET /records` and `/adjustendpoints` encode an empty result as `[]`, never `null`.
- TXT in a change set: `SetTXT(records.TXT{Name: dnsName as received, Targets: as received, OwnedRecord: labels["ownedRecord"]})`; validated by `Policy.CheckTXT`.
- A/AAAA set: refuse with `records.ErrConflict` when `d.Source(name)` is `api`; else `d.Set(name, type, values, SourceExternalDNS)`. A/AAAA delete of an `api` name: refuse. TXT set or delete whose `ownedRecord` label names an `api` name: refuse.
- Any error from `Apply`, a malformed body, or a body over 1 MiB: status 500, body `{"error":"..."}`.
- The dropped-endpoint report: the handler remembers the previous sorted `dropped` list; when it differs, log at warn and `hist.Add` an entry with status 200, path `/adjustendpoints` and summary `dropped: <descriptions joined by "; ">` (or `dropped: none` when it becomes empty).
